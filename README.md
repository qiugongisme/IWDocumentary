# IWDocumentary（我看纪录片）

> **项目定位**：一个极简、高颜值的纪录片浏览导航入口。告别不便捷的网页，将所看所喜欢的纪录片，聚合为简约美的网页，实现“一秒定位，沉浸观看”。

## ✨ 初衷

传统网页查找繁琐，本项目通过 AI技术合理地抓取数据封装为**网页应用**。
您只需通过浏览器打开对应的 HTML 文件，即可快速筛选，让观看即刻开始。

## 🚀 便捷入口特性

- **📱 响应式卡片布局**：手机、平板、电脑自适应，随时随地翻阅。
- **🔍 一键筛选导航**：按“稻作”、“旱作”、“林菇”等系统分类，精准直达感兴趣剧集。
- **🎨 视觉沉浸**：搭配纪录片级大图与金句摘要，营造观看仪式感。
- **⚡️ 零依赖**：纯原生三件套（HTML + CSS + JS），无需安装任何依赖，双击即用。

# 持续更新片单
## 2. 《农耕探文明》系列

《农耕探文明》是央视推出的系列大型纪录片，系统展现中国重要农业文化遗产。
从江西万年稻作、内蒙古敖汉旱作，到浙江青田稻鱼共生、庆元林菇共育，影片跨越数千年农耕历程，揭示了中华民族“应时、取宜、守则、和谐”的生态智慧。
它不仅记录古老农作技艺，更探寻农业文化遗产在当代的活态传承与可持续发展，呈现了一幅天人合一、生生不息的农耕文明图景。

## 1.《中国影像方志》系列

《中国影像方志》是中央电视台出品的大型纪录片，首播于2017年。节目以全国各县和县级市为拍摄主体，每一个县1集、每集40分钟左右，堪称影像版的“地方百科全书”。

作为大型文化影像工程，《中国影像方志》从中华文明的角度解读地方志、从地方志的角度彰显中华文明，以局部展示整体、以地方表达中国，从而为时代讴歌，为人民立传。
